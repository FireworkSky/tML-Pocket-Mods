# tML Pocket Mods

Source projects for mods maintained for tML Pocket Launcher. Each mod lives in its own directory and keeps its tModLoader source, metadata, assets, localization and provenance notices together.

## MobileJoystick

`MobileJoystick/` contains the launcher-maintained mobile controls mod. The launcher build compiles and packages it with the tModLoader packager, then installs it as a built-in mod. Its project accepts `LauncherRoot` to locate the launcher's precompiled game references and MonoMod dependencies.

The mod source was supplied by the project owner. See `MobileJoystick/UPSTREAM.md` and the asset source notices for provenance and licensing details.
